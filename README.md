# 时间戳转换器 ⏰

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

秒 / 毫秒时间戳 ⇄ 日期时间互转，带实时时钟与快捷时间入口。单个 HTML 文件，无框架、无依赖、无外部请求，双击即可使用。

## ✨ 功能

- **实时时钟**：当前时间 + 秒级 / 毫秒级 / ISO 时间戳，点击即复制
- **时间戳 → 日期**：自动识别 10 位（秒）与 13 位（毫秒），显示本地时间、UTC、北京时间、星期、距今
- **日期 → 时间戳**：日期选择器或手输时间，一键得到秒级 / 毫秒级时间戳
- **快捷时间**：今天 0 点、明天、昨天、一周后、月末最后一天、明年今日

## 🚀 在线体验

👉 点击打开：<https://sunfloweandnefertari.github.io/timestamp-tools/>

- **方式一**：直接双击 `index.html` 在浏览器打开
- **方式二**：部署到任意静态服务器（GitHub Pages / Gitee Pages / Nginx …）

## 📦 技术

原生 HTML + CSS + JavaScript，零依赖，离线可用。
